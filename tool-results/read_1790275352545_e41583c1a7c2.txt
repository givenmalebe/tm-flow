     1→# TenderFlow - Tender Management System Worklog
     2→
     3→## Project Overview
     4→Building a full-stack Tender Management System with:
     5→- **Backend**: Python FastAPI + SQLAlchemy + SQLite (port 8000)
     6→- **Frontend**: Next.js 16 + TypeScript + shadcn/ui (port 3000)
     7→- **AI**: z-ai-web-dev-sdk CLI for document reading, assistant, summaries
     8→
     9→## Architecture Decisions
    10→- Python backend runs as a mini-service on port 8000
    11→- All frontend API requests use `?XTransformPort=8000` to route through Caddy gateway
    12→- JWT auth with bcrypt password hashing
    13→- SQLite database stored at `mini-services/tender-api/tender.db`
    14→- File uploads stored at `mini-services/tender-api/uploads/`
    15→- AI features: Python backend shells out to `z-ai` CLI (chat + vision)
